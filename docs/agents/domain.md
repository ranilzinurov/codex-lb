# Документация предметной области

Репозиторий использует single-context-размещение документации предметной
области.

## Что читать перед исследованием кода

- Корневой `CONTEXT.md`, если он существует.
- Относящиеся к изменяемой области ADR из `docs/adr/`, если каталог существует.

Отсутствие этих файлов не является ошибкой и не требует их предварительного
создания. Они появляются только тогда, когда необходимо закрепить терминологию
или архитектурное решение.

## Правила использования

- В названиях задач, тестов и проектных решениях используется терминология из
  `CONTEXT.md`.
- Если необходимого понятия нет, сначала проверяется, не изобретается ли лишний
  синоним. Реальный пробел фиксируется через моделирование предметной области.
- Противоречие существующему ADR отмечается явно; навык не заменяет решение
  молча.

Ожидаемая структура:

```text
/
├── CONTEXT.md
├── docs/adr/
└── исходный код
```
