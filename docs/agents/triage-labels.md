# Метки triage

Навыки используют пять канонических ролей. В этом репозитории каждой роли
соответствует одноимённая метка GitHub.

| Роль навыка | Метка GitHub | Назначение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется оценка сопровождающего |
| `needs-info` | `needs-info` | Ожидается дополнительная информация |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова к выполнению агентом |
| `ready-for-human` | `ready-for-human` | Требуется выполнение человеком |
| `wontfix` | `wontfix` | Задача не будет выполняться |

Когда навык называет роль, применяется соответствующая метка из правого
столбца.
